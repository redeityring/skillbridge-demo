# SkillBridge

**От знания — к применению.** EdTech-прототип для VentureHack 2026 (трек EduTech), который измеряет не «что ученик запомнил», а «что он умеет применять» — и закрывает разрыв практикой.

> Диагностика → Разрыв → Мост → Переоценка → Прогресс. Один замкнутый продуктовый цикл, доведённый до конца, вместо набора недоделанных функций.

---

## Проблема

Ученик может идеально ответить на вопрос «что такое альтернативная стоимость» — и тут же ошибиться в простейшем жизненном сценарии, где её нужно применить. Обычные тесты это скрывают: правильные ответы на определения дают иллюзию знания. Настоящий разрыв — между **пониманием** и **применением** — остаётся невидимым, а значит, его невозможно закрыть адресно.

## Решение

SkillBridge за один заход:

1. **Диагностика** — 4 вопроса на понимание + 3 сценария на применение. Не «правильно/неправильно», а оценка рассуждения: ученик выбирает вариант и объясняет ход мысли своими словами.
2. **Разрыв** — приложение считает разрыв между теорией и применением по каждому навыку и показывает его наглядно, с конкретным диагнозом заблуждений.
3. **Мост (Bridge)** — короткая адресная практика ровно по тем навыкам, где выявлен разрыв (генерируется AI под слабости ученика, с курируемым банком как фолбэком).
4. **Переоценка** — те же типы сценариев после практики.
5. **Прогресс** — «до/после» по каждому навыку, история заходов, движение разрыва.

Всё считается по одинаковым правилам: три измерения (узнавание понятия · рассуждение · применение к контексту) с фиксированными весами. Ни один балл не захардкожен.

## Как оценивается ответ

Оценку выполняет **двухуровневый движок**:

- **AI-оценка** — ответ вместе с рубрикой вопроса (концепции, признаки рассуждения, обязательная мысль) уходит в модель через **OpenRouter**. Ключ хранится только на сервере, в браузер не попадает.
- **Локальный рубричный движок (фолбэк)** — если AI недоступен (лимит, сеть, таймаут), ответ оценивает детерминированный рубричный движок: работает с кириллицей, знает русские стоп-слова и причинные маркеры, оценивает *реальный* ответ ученика.

Какой движок отработал — всегда видно в интерфейсе (бейдж «Живой AI · модель» / «Локальный рубричный движок»). Продукт никогда не выдаёт локальную оценку за AI и наоборот. Цепочка бесплатных моделей OpenRouter с авточейном фолбэком означает, что одна перегруженная модель не ломает продукт посреди защиты.

| Уровень | Что происходит |
|---|---|
| 1 | Один запрос с группой лучших бесплатных моделей — роутер OpenRouter сам фолбэкает внутри |
| 2 | Если ответ пришёл, но не разобрался — обход цепочки модель за моделью с жёстким дедлайном |
| 3 | Честная деградация: локальная рубрика, подписанная в UI |

## Мультиязычность

- **Русский и английский** — весь интерфейс, все вопросы, сценарии, рубрики, демо-ответы и фидбек AI.
- **По умолчанию — язык системы** (первое открытие), выбор запоминается, переключатель — в шапке.
- Язык едет с каждым запросом на сервер: оценка и генерация практики выполняются на языке ученика, смешения языков в одном ответе не бывает.
- Русский не «перевод поверх»: это полноценный банк контента со своими рубриками — движок оценивает русские ответы по русским признакам рассуждения.

## Технологии

- **Next.js 16 (App Router) + TypeScript** — серверные API-роуты держат ключ и рубрики, клиент не доверяет ничего важного.
- **Tailwind CSS 4** — стеклянные поверхности, aurora-фон, адаптив от 360px.
- **OpenRouter (только бесплатные модели)** — оценка ответов и генерация практики; работает на одном бесплатном ключе.
- **Zod** — все внешние данные (ответы API, AI-ответы, сгенерированные задания) проходят валидацию схемой.
- **localStorage** — прогресс захода и история результатов переживают перезагрузку.

## Структура кода

```
src/
├── app/                  # Экраны: home, diagnostic, gap, bridge, reassess, progress
│   └── api/              # evaluate, bridge, ai/status — серверная логика
├── components/           # UI-примитивы и продуктовые компоненты
├── content/              # Банк контента: en/ и ru/ (вопросы, сценарии, рубрики)
├── lib/
│   ├── ai/               # Клиент провайдера, промпты, схемы, задачи
│   ├── i18n/             # Конфиг локали, словари, контекст
│   ├── rubric.ts         # Локальный рубричный движок (фолбэк)
│   ├── scoring.ts        # Веса и пороги — единственный источник
│   └── bridge.ts         # Планировщик практики и курируемый банк
└── types/                # Доменные типы
```

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать OPENROUTER_API_KEY (бесплатный)
npm run dev
```

Ключ OpenRouter создаётся бесплатно на openrouter.ai → Keys. Без ключа продукт тоже работает: все ответы оценивает локальный рубричный движок (бейдж это честно покажет).

**Демо для защиты:** кнопка «Запустить демо» на главной проходит весь цикл на заготовленных ответах — история «100 → разрыв ~17 → ~80 после практики» проигрывается без ручного ввода. Демо-ответы сценарные, но оценивает их настоящий движок, поэтому цифры на экране живые.

## Соответствие критериям VentureHack 2026

| Критерий | Баллы | Чем закрыт |
|---|---|---|
| Понимание проблемы и потенциальный эффект | 0–20 | Реальный, проверяемый разрыв «понимаю ≠ применяю»; эффект — адресная практика вместо повторного теста |
| Инновационность и креативность | 0–20 | Измерение рассуждения, а не факта: открытый ответ оценивается AI по рубрике; разрыв считается, а не угадывается |
| Качество решения и техническая реализация | 0–25 | Полный рабочий цикл из 5 экранов, двухуровневый движок оценки с честной деградацией, валидация всех данных, серверное хранение ключа |
| Практическая реализуемость | 0–15 | Стандартный стек, один бесплатный API-ключ, работает без ключа; масштабируется на другие предметы добавлением банка контента |
| Валидация и доказательность | 0–10 | Демо-сценарий построен на реальных заблуждениях учащихся; прогресс «до/после» даёт измеримое доказательство эффекта |
| Презентация и коммуникация | 0–10 | Встроенный демо-режим на 60 секунд, виджет прогресса и разрыва говорят сами за себя |
